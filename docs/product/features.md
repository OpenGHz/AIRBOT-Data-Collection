# 功能清单

本文档从产品视角总结 AIRDC 当前已经具备或正在强化的能力。

## 采集与控制能力

| 功能 | 主要受益人 | 当前状态 |
| --- | --- | --- |
| 配置驱动启动采集流程 | 采集操作员、平台维护者 | 已具备，默认入口为 `airbot_ie/configs/config.yaml` |
| 键盘 / GUI / 手柄 / 自动化 manager | 采集操作员、平台维护者 | 已具备，按 manager 组合启用 |
| FSM 控制 configure / activate / sample / save / finish | 全部角色 | 已具备，是当前主流程核心 |
| 多 FSM 批量采集 | 平台维护者 | 已具备，依赖 `batch_size` |

## 数据保存能力

| 功能 | 主要受益人 | 当前状态 |
| --- | --- | --- |
| MCAP episode 保存 | 数据工程师、平台维护者 | 已具备，是真机默认路径 |
| MCAP metadata / attachment / topic statistics | 数据工程师 | 已具备，保存时自动写入 |
| ROS structured MCAP | 数据工程师、平台维护者 | 已具备，主要用于仿真 / ROS 风格链路 |
| LeRobot dataset 保存 | 数据工程师 | 已具备，仍需要更多契约测试与文档巩固 |
| 视频编码与旁路视频目录 | 数据工程师 | 已具备，行为受 sampler 配置影响 |

## 观测与可视化能力

| 功能 | 主要受益人 | 当前状态 |
| --- | --- | --- |
| 实时 OpenCV 可视化 | 采集操作员 | 已具备，当前默认可视化路径 |
| Tk / Matplotlib / Web 可视化 | 平台维护者 | 已具备，适合按需扩展或实验 |
| Foxglove / PlotJuggler / AIRBOT Viewer 消费已保存数据 | 数据工程师 | 已具备，对应文档已存在 |

## 数据质量与运维能力

| 功能 | 主要受益人 | 当前状态 |
| --- | --- | --- |
| 数据检查脚本 | 数据工程师、平台维护者 | 已具备，重点覆盖 MCAP 数据集检查 |
| 上传能力 | 平台维护者 | 已具备基础实现，依赖额外安装的上传客户端 |
| 性能分析脚本 | 平台维护者 | 已具备，位于 `scripts/` |

## 扩展能力

| 功能 | 主要受益人 | 当前状态 |
| --- | --- | --- |
| 新 demonstrator / sampler / visualizer / manager 接入 | 平台维护者 | 已具备，推荐通过类实现 + Hydra 配置完成 |
| AIRBOT 真机与 auto-atomic-operation 共享核心 runtime | 平台维护者 | 已具备，但外部依赖耦合仍需持续整理 |

## 当前最值得继续强化的能力

- LeRobot 路径的测试覆盖和操作文档
- 外部依赖与符号链接约束的显式化
- 当前文档与未来规划的分层维护
