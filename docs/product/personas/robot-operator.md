# Persona：采集操作员 / 集成工程师

## Who They Are

- 负责把机器人、相机、示教器和电脑连起来并开始采集
- 通常熟悉设备接线、基本命令行和配置文件
- 关注“今天能不能稳定采到数据”

## Pain Points

- 设备号、USB 口、CAN 绑定容易变化
- 真机链路出问题时，很难快速判断是配置、驱动还是硬件问题
- 采集后如果数据有问题，希望尽快定位而不是返工整轮流程

## Journey

1. 阅读环境配置与机器人安装文档
2. 准备默认配置并检查相机 / 机器人连通性
3. 启动 `airdc` 进行采集和保存
4. 用可视化或检查脚本确认数据质量
