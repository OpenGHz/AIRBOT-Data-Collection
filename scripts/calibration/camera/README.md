## Usage

### 准备标定板

注意：

- 使用真正平整的标定板对于获得高质量的相机内参标定至关重要。标定算法的核心假设是：所有特征点都位于同一个平面上。如果使用胶带随意粘贴的纸张或已发生翘曲的纸板作为标定板，将严重损害标定结果的准确性。
- 内参与外参标定可使用不同的标定板（需要在运行每次标定前相应地调整标定板的定义参数）。内参标定时可选用一块更加平整、对齐精度更高的标定板；而在进行外参标定时，则可使用由多张纸拼接而成的更大尺寸标定板，以覆盖更大的捕捉空间，便于多相机系统的外参标定。
- 每台相机短期内理论上只需进行一次有效内参标定。
- 为确保外参准确，请测量标定板上打印方格的实际边长。虽然该测量值的误差不会导致标定流程失败，但可能外参值过大或过小。请注意，即使您严格按照目标尺寸打印标定板，实际方格尺寸仍可能存在微小偏差。

#### 内参

相机内参标定使用标准的棋盘格标定板。

#### 外参

外参标定借助 ChArUco 标定板完成。这种标定板本质上是一种在棋盘格内部嵌入了 ArUco 标记的特殊棋盘，可用于同时确定相机的内参（如光学中心、焦距和镜头畸变）以及各相机之间的相对位置关系（外参）。

您可以购买预先打印好的标定板，然后根据实际标定板的规格设置 ChArUco 参数。请注意：行数（row count）和列数（column count）不可互换。请将您手中的实体标定板与图形界面（GUI）中显示的标定板进行视觉比对，确保两者一致。如有必要，您可能需要交换行数和列数的数值。

ChArUco 标定板同时可支持内参和外参标定，省去了额外打印标定板的麻烦。默认标定板图案文件位于`charuco.png`，直接打印使用即可，该图案对应的参数信息位于`config.toml`。如果希望使用其他图案，请参考[caliscope文档](https://mprib.github.io/caliscope/calibration_board/)。打印完成后，准备好剪刀和胶带，将图案粘贴到标定板主体上即可使用。


### 视频录制

准备好标定板后就可以对其录制视频了。

#### 内参

```bash
airdc +demonstrator.components.ignore_roles="[l,f]" samplers=video_each +dataset.root=scripts/calibration/camera/calibration/ dataset.directory=intrinsic
```

上述命令会同时启动多个相机，但会依次采集每个相机的视频数据，采集顺序与配置文件中相机的顺序一致。
因此，首先查看配置文件中第一个相机的名称，然后将标定板放置在该相机前方进行录制，保存后，下一次采集会自动按顺序切换到下一个相机，依次类推，完成所有相机的视频采集。完成后，将会在`dataset.directory`指定的目录下找到每个相机的视频文件，命名形如`port_#.mp4`,其中`#`与相机的录制顺序对应。

有如下录制建议：

- 自由移动相机或标定板
  - 在直接监看相机画面时，更容易采集到高质量的数据。
  - 相机的位置无需与外参标定时完全一致（标定板也不必使用同一个）。

- 尽量减少运动模糊：
  - 动作要缓慢、平稳。
  - 使用较高的快门速度以减少运动模糊。
  - 确保充足的照明，以便在不使视频曝光不足的前提下使用更快的快门速度。

- 提供透视缩短（Foreshortening）效果：
  - 将标定板以不同角度朝向相机摆放。这种透视缩短对校准过程至关重要，因为它能提供更多关于相机镜头特性的信息。
  - 拍摄时应包含多种姿态：有些画面中标定板朝向相机倾斜，有些远离相机，还有一些呈侧向角度。

- 覆盖整个视场范围：
  - 在整个相机视场范围内移动标定板，以确保校准能涵盖图像传感器全域的镜头畸变及其他特性。

- 使用高质量的标定板：
  - 标定板应打印在平整、坚硬的材料上，防止翘曲变形。

- 改变拍摄距离：
  - 在不同距离处拍摄标定板，有助于理解相机在不同景深下的聚焦特性。

- 保持对焦一致：
  - 如条件允许，请使用手动对焦，以在整个录制过程中保持焦点稳定。
  - 自动对焦可能会在不同镜头间产生不一致，影响标定效果。

- 充足且合适的照明：
  - 确保场景光线充足，避免视频中出现噪点和颗粒，这些会干扰标定过程。
  - 避免使用强烈的直射光源，以免在标定板上产生眩光或阴影。


#### 外参（相机相对值）

这里标定的是多个相机之间的相对外参关系，而不是相机与机械臂等其他设备的外参关系。

```bash
airdc +demonstrator.components.ignore_roles="[l,f]" samplers=video_once +dataset.root=scripts/calibration/camera/calibration/ dataset.directory=extrinsic
```

上述命令会同时启动多个相机，并同时采集所有相机的视频数据。多次重复录制会覆盖之前的数据。完成后，将会在`dataset.directory`指定的目录下找到每个相机的视频文件，命名规则与前述内参标定时一致。

有如下录制建议：

- 确保覆盖范围与视场重叠：
  - 移动 Charuco 标定板时，应覆盖所有相机视场相互重叠的整个空间区域。
  - 确保不同相机之间有充足的视场重叠区域，这对多相机系统的标定至关重要。

- 使用方格尺寸足够大的标定板：
  - 较大的 ArUco 标记可以从更远距离被可靠识别，从而支持更大捕捉体积的标定。

- 尽量减少运动模糊：
  - 运动模糊会严重影响角点检测的准确性。
  - 使用更高的帧率有助于减轻运动模糊。
  - 但更高的帧率通常需要更强的照明，以维持良好的画面亮度。

- 保持对焦一致：
  - 如条件允许，请使用手动对焦，以在整个录制过程中保持焦点稳定。
  - 自动对焦可能在不同帧之间产生不一致，影响标定效果。

- 用标定板定义坐标系原点（便于后续处理）：
  - 此操作仅为方便，并非强制要求。
  - 将标定板垂直持握并使其底部接触地面。
  - 确保标定板左上角（如 Charuco 页面所示）处于相机视野内，并同时接触地面。

### 标定

#### 内参

```bash
python3 scripts/calibration/camera/calibrate_intrinsic.py --board-size "[11,8]" --square-size 0.02 --frame-interval 3 --max-frames 20
```

参数说明：
- `--board-size`：标定板的行数和列数
- ``--square-size``：标定板上每个方格的实际边长，单位任意（建议使用米）
- `--frame-interval`：从视频中采样帧的时间间隔，默认为1，即每帧都采样
- `--max-frames`：用于标定的最大帧数，默认为20

运行后会依次对`intrinsic`目录下的每个视频文件进行标定，终端实时打印简要标定信息，标定结果保存在`outputs/intrinsic`目录下，每个相机对应一个文件夹（以相机名称命名），包含以下文件：
- `calibration.yaml`：标定结果文件，包含相机内参矩阵、畸变系数、重投影误差、分辨率、标定使用的图像点和对应的物理点、FOV等信息
- `undistorted`：该文件夹下包含标定过程中使用的图像帧（绘制有识别结果）去畸变后的图像

其中，RMSE重投影误差是衡量标定质量的重要指标，通常该值越小，标定结果越准确。一般来说，RMSE小于0.2为佳，0.2到0.5之间略微欠佳，0.5到1.0之间也可接受，如果大于1.0则需要重新标定。
由于是使用视频进行标定，因此视频帧的选取对标定结果影响较大，其中主要取决于``--frame-interval``和``--max-frames``参数的设置。建议多尝试不同参数组合以获得更优的标定结果，比如
可以尝试减小`--frame-interval`或增大`--max-frames`等。如果多种参数组合均无法获得满意的标定结果，建议重新录制视频数据后再重新标定。

#### 外参

本标定流程需要依赖[caliscope](https://github.com/mprib/caliscope?tab=readme-ov-file)，需要先安装该库：

```bash
pip install caliscope
```

命令行执行`caliscope`，打开标定程序界面。左上角选择`File -> New/Open Project`打开`airdc/scripts/calibration/camera`。
